## About

I'm an AI engineer at [TernoAI](https://github.com/terno-ai), building LLM agents that work with enterprise data. I built [TernoDBI](https://github.com/terno-ai/ternodbi), the database layer our agents use to query company databases, and these days I work across the rest of the agent stack.

- Before this: Data Science & ML intern at CloudxLab, Product R&D intern at Tata Steel
- B.Tech from IIT Jodhpur (CGPA 8.15)
- Interested in LLM agents, applied ML and data infrastructure
- Outside work I make [short films](https://www.youtube.com/@Navin_bhagat), take photos and train at the gym
